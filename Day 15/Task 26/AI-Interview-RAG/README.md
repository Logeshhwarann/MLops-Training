# Interview RAG Assistant
A Retrieval-Augmented Generation (RAG) based interview preparation platform built using Flask, ChromaDB, Sentence Transformers, and Gemini/OpenAI.

## Features
- Upload PDFs and interview notes
- Semantic document retrieval
- AI-powered question answering
- Mock interview generation
- Skill gap analysis
- Job Description matching

## Tech Stack
- Python
- Flask
- ChromaDB
- Sentence Transformers
- Gemini/OpenAI
- RAG Architecture

## Run
pip install -r requirements.txt
python app.py
